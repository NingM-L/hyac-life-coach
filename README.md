# Hyac Life Coach

Hyac Life Coach 是一个面向 RikkaHub Agent 手机端的长期学习教练 Skill。

## 主要功能

- 用户学习画像
- 基础水平测试
- 六个月学习计划
- 西蒙学习法
- 输出式学习
- 每日学习汇报
- 听力、口语、阅读、写作训练
- 每周总结
- 每月总结
- Nexus 式任务管理
- 主动学习提醒
- 学习支出记录

## 安装

进入 Releases，下载：

`hyac-life-coach.zip`

解压后导入 RikkaHub Agent。
